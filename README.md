# Aayush Patel — Portfolio Quest

A 3D Pac-Man style portfolio built with Three.js (vendored in `vendor/`, no build step).
Eat dots, dodge the bugs, and grab the 5 glowing orbs to unlock About / Skills / Projects / Experience / Contact.

## Run
    python3 -m http.server 8000   # then open http://localhost:8000

(ES modules need a server; opening index.html via file:// won't work.) Works on GitHub Pages as-is.

## Customize
Edit `content.js` — name, role, and all section text/links.

## Controls
Arrows/WASD (or swipe / on-screen d-pad), `C` camera, `M` mute, `P` pause. "Plain view" shows everything without playing.
